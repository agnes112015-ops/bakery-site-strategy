# 남부터미널역 베이커리 출점 전략 (PE 보유 커피·베이커리 브랜드)

**결론:** 서울 1호 신규 출점지는 서초구 남부터미널역 상권(서초1동). 3년 연속 가속 성장(2분기 YoY +0.7% → +7.1% → +17.5%), 점포 감소 속 베이커리 매출 증가(7.42억 → 9.61억 원), 500m 내 프리미엄 베이커리 공백. 단, 실제 월 임대료가 손익분기 상한(기준 시나리오 Y1 약 335만 원) 이하인 매물이어야 함.

- 페이지: `site/index.html` (GitHub Pages) · 발표 영상: `site/assets/presentation.mp4`
- 데이터: 서울 열린데이터광장 Open API(상권분석서비스·인허가) + DART 감사보고서만 사용. 모든 수치에 출처 표기.
- 재현: `scripts/collect_*.py`(수집, 원천은 `data/raw/` — 저장소 미포함) → `scripts/analyze.py` → `scripts/build_*.py` → `scripts/build_site.py`
- 한계: 상가 임대료 공공데이터 없음(역산 상한으로 대체), 아파트·소득소비 API 서버 오류, 파리바게뜨 운영법인 2025 공시 미확인.
